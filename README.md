# Mechanical Dragonfly · 可互動機械蜻蜓

單檔離線 HTML，用瀏覽器打開即可：

- 拖曳旋轉
- 滾輪 / 雙指縮放
- 按鈕：暫停拍翅、打開/關閉胸部、重置視角

## 線上預覽

直接打開 [index.html](./index.html)

或使用下方 raw 連結（適合分享到 Threads）：

https://htmlpreview.github.io/?https://github.com/whocare-lab/mechanical-dragonfly/blob/main/index.html

## 本機使用

下載 `index.html` 後用瀏覽器開啟即可，不需伺服器。
